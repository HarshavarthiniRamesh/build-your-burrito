# Build your burrito 🌯

An interactive, paper-cut stop-motion take on a build-your-own burrito counter.
Pick your meal, rice, beans, fillings, salsas, toppings, dessert and drink, and watch
the staff build it on your tray, station by station, until it's handed over at the till.

- `index.html` — the paper-cut edition (main)
- `soft.html` — an earlier soft-illustration version

Plain HTML, CSS and JavaScript in single files: no build step, no dependencies.
Open `index.html` in a browser, or serve the folder with any static host.

Tip: add `#demo4` (or any step number, e.g. `#demo8-bowl`) to the URL to jump to a step with a sample order.
